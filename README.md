# HideStream

A lightweight Paper/Spigot 1.21.x plugin that hides player join, quit, death, and advancement messages from chat to prevent stream sniping.

## Features
- Hide Join/Quit messages.
- Hide Death messages.
- Hide Advancements.
- Send hidden messages to the console for admins.
- Fully configurable via `config.yml`.

## Commands
- `/hidestream reload` - Reload the configuration (Permission: `hidestream.admin`).
